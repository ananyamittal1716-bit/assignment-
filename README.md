## The `print()` function

### What it does

`print()` **displays output on the screen**. You use it to show text, numbers, or results of calculations.

---

### Basic example

```python
print("Hello, world!")
```

📌 Output:

```
Hello, world!
```

---

### Printing numbers

```python
print(10)
print(3.14)
```

---

### Printing multiple things

```python
print("My age is", 20)
```

📌 Output:

```
My age is 20
```

---

### Printing the result of a calculation

```python
print(5 + 3)
print(10 * 2)
```

📌 Output:

```
8
20
```

---

### Why `print()` is important

* It helps you **see what your program is doing**
* It’s great for **learning, debugging, and testing**
